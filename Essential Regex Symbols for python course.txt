Essential Regex Symbols for the Google python course.

    \d — Digit (0-9)
    \D — Non-digit
    \w — Word character (letters, digits, underscore)
    \W — Non-word character
    \s — Whitespace (space, tab, newline)
    \S — Non-whitespace
    . — Any character except newline
    ^ — Start of string
    $ — End of string
    * — Zero or more repetitions
    + — One or more repetitions
    ? — Zero or one repetition (optional)
    {n} — Exactly n repetitions
    {n,} — At least n repetitions
    {n,m} — Between n and m repetitions
    [] — Character class (matches any one character inside)
    [^] — Negated character class (matches any character not inside)
    () — Capturing group (extract matched text)
    | — Alternation (OR)
    \ — Escape special character (e.g., \[ to match literal [)
